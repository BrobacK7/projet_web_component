Projet Web Components 2025-2026

Ce depot contient des Web Components audio reutilisables:
- audio-bus
- audio-player
- audio-equalizer
- audio-visualizer (modes fft, waveform, volume)
- audio-reverb
- audio-workspace

Documents fournis:
- README.md: presentation generale et architecture
- SPECIFICATION.md: API detaillee de chaque composant
- IA_POSTMORTEM.md: usage des outils IA, prompts et decisions
- RENDU_CHECKLIST.md: checklist de rendu final

Integration par URI:
Les composants peuvent etre utilises via balises script type="module" pointant vers les URLs publiques des fichiers dans /components.

Note:
Le support WAM peut etre ajoute en extension (voir SPECIFICATION.md section extension future).
